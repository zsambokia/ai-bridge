# ADR-018: Adopt One Common Engine Constitution

**Decision:** accepted.

Adopt [Engine Constitution](../ENGINE_CONSTITUTION.md) as the common ownership
and interaction rule for all Domain Engines. Domain-specific documents may
refine bounded responsibilities, but MUST NOT create parallel constitutions or
direct-call exceptions.
