# ADR-011: Product Owner Cognitive Model

**Status:** Implemented in ORKI-008; Product Owner foundation acceptance recorded.
**Date:** 2026-08-02

## Context

Mission and Project state alone cannot make Orki an adaptive Digital COO. The
Product Owner directed a distinct model for evidence-backed operational working
patterns before further Recommendation Intelligence expansion.

## Decision

Adopt a separate, revisioned Product Owner Cognitive Model, documented in
[the canonical contract](../ORKI_PRODUCT_OWNER_COGNITIVE_MODEL.md). It stores
only bounded operational collaboration patterns as explainable Cognitive State
artefacts. It is evidence-linked, correctable, reviewable, versioned and
project-aware; transcripts and personal data are excluded.

The model consists of an isolated project-aware default plus an owner baseline
only where evidence is explicitly portable under policy. It may adapt safe
defaults and explanation depth but has no governance, execution or decision
authority.

## Consequences

- ORKI-008 precedes any further expansion of Recommendation Intelligence.
- Product Owner Understanding becomes an independently measured DCMI
  dimension, not a UX or implementation proxy.
- Cross-project strategic initiative cannot use profile information unless the
  same explicit portability and aggregation policy is met.
- Existing recommendations remain valid but must not claim adaptive owner
  reasoning until ORKI-008 evidence passes.
