# ADR-014: Establish an Architecture Constitution

**Decision:** accepted.

## Context

AI Bridge has accumulated valuable Runtime, Orki, operational-engine, and
assessment material, but readers lacked one normative technical hierarchy and
one technical entry point.

## Decision

Adopt [Architecture Constitution](../ARCHITECTURE_CONSTITUTION.md) below the
Bridge Constitution. The [Architecture Map](../ARCHITECTURE_MAP.md) is the
sole technical-architecture entry point. Runtime 2.0 and the specialized
constitutions refine the Architecture Constitution without creating a parallel
repository constitution.

## Consequence

Existing documents retain their evidence-based status and are classified
canonical, supporting, transitional, or historical through front matter.
