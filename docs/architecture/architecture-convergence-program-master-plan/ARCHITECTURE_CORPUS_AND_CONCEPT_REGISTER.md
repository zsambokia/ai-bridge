## Concept laws

- Exactly one direct Scope owner for every persistent object; Repository and Provider are Resources.
- Conversation is a first-class interaction; Factory Chat is a UI/projection, not Runtime.
- MSM exclusively owns Mission lifecycle; operational delivery never becomes a Mission.
- Domain Engines own business capability; Kernel owns Execution; Operational Foundation owns mechanical handoff/delivery.
- Context Packages and canonical versions used for execution are immutable.
- English technical identifiers are stable; eligible semantic content is multilingual; original Evidence is never replaced by translation.
