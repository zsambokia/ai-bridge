# Architecture

The [Architecture Constitution](ARCHITECTURE_CONSTITUTION.md), including its
approved Constitution Book entries, defines the target architecture. The
[Architecture and Implementation Convergence
Governance](ARCHITECTURE_IMPLEMENTATION_CONVERGENCE_GOVERNANCE.md) defines who
may change that target and how implementation feeds evidence back through an
Architecture Challenge.

The [Architecture Map](ARCHITECTURE_MAP.md) remains the technical-topology
entry point. It is a historical/transitional map where its terminology or
topology differs from an approved target Constitution entry.

For repository realization, use the [Implementation Convergence Program —
Phase 2](implementation-convergence-program-phase-2-repository-alignment-assessment/README.md)
and its successor implementation contracts. Historical convergence records do
not define canonical architecture merely because they remain accessible.
