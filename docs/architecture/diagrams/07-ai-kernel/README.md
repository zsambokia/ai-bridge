# Diagram 07 — AI Kernel

## Purpose

Canonical logical source: [`07_AI_KERNEL.md`](07_AI_KERNEL.md) (Mermaid). The `.drawio` file is its derived, editable visual representation.

Defines the AI Kernel as the technical execution core after Operational
Foundation admission.

## Responsibility and ownership

Kernel Managers, Registries, and Objects create and own first-class Execution,
resolve Capability and Provider paths, integrate immutable Context Packages,
emit Kernel Events, and record Evidence. It owns neither Mission lifecycle nor
Operational Foundation delivery mechanics.

## Contracts, lifecycle, and rules

Admitted immutable work becomes a Kernel-owned Execution. Capability resolution
precedes Provider Integration. Context is immutable, versioned, reproducible,
evidence-based, and auditable.

## Failure, evidence, and open questions

Kernel failure yields attributed events and Evidence for the owning recovery
policy. Detailed Execution Attempt semantics remain ADR-governed.
