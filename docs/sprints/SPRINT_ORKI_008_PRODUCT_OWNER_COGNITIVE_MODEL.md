# Sprint ORKI-008 - Product Owner Cognitive Model

**Status:** PASS — READY FOR PRODUCT OWNER REVIEW
**Epic:** Orki Cognitive Operating System
**Authority:** Product Owner strategic directive, 2026-08-02.
**Prerequisites:** ORKI-001 through ORKI-007 accepted; DCMI v1 is 66/100.

## Objective

Prove that Orki learns an explainable, correctable, evidence-backed model of
how the Product Owner works operationally. This is not personalisation: it is a
bounded, project-aware working relationship model that can safely adapt COO
guidance without using transcript history as memory.

## Scope

- Add revisioned Product Owner Cognitive State artefacts and a bounded
  projection for the permitted operational dimensions.
- Link every active profile observation to attributed state evidence, rationale,
  confidence, scope and correction/supersession history.
- Provide Product Owner inspection, correction and review; prove that an
  attributable correction changes the adaptive output explainably.
- Implement project-aware isolation and explicit, policy-bound owner-baseline
  portability only where applicable.
- Make a profile able to influence a reversible recommendation default or
  communication/planning depth, never a material decision or authority.

## Explicit exclusions

- No personal-data, personality or raw-transcript profile.
- No unproven cross-project inference or project-fact disclosure.
- No new recommendation, planning, decision, governance, delivery or execution
  authority.
- No DCMI increase based only on persisted fields, UI or model prose.

## Release Gate

PASS requires all repository gates plus the six executable scenarios in
[Product Owner Cognitive Model](../architecture/ORKI_PRODUCT_OWNER_COGNITIVE_MODEL.md).
The independent assessment must prove ten-interaction learning, neutral
fallback without evidence, correction, versioning, explainability, conflict
handling, isolation, transcript separation and absence of authority side
effects. Green automated tests alone are a FAIL.

## DCMI rule

The Sprint may change only the Product Owner Understanding dimension and only
after final-state behavioural evidence is independently assessed. Its release
does not preallocate a score for Recommendation, Planning, Decision or
Initiative maturity.
