# Memory Audit

## What exists

| User question | Current canonical answer |
| --- | --- |
| “Show examples / decisions from last week.” | Search/retrieval can return governed active knowledge when it was captured with time/provenance; there is no audited natural-language time interpretation layer. |
| “Why was this roadmap created?” | Cognitive State/Factory Plan and roadmap projections can explain current recorded rationale; a durable decision must be in governed knowledge for recall beyond the session. |
| “What was discussed during Bootstrap?” | Repository bootstrap artifacts can become reviewed knowledge; transcript itself is not memory. |
| “Continue yesterday’s work.” | Factory Chat session and persisted project context can restore a project-bound conversation; continuation is not proof of an approved execution scope. |

## Boundaries

- `FactoryChatMessage` is a transcript, not canonical memory.
- Cognitive State is the live working context.
- `KnowledgeEntry` is governed durable knowledge; a candidate requires review.
- `KnowledgeContextPackage` is a retrieved, persisted package, not a memory
  database or prompt cache.

## Gaps

The current Workspace has no dedicated decision timeline, meeting knowledge
owner, temporal query interpreter, or cross-artifact explanation projection.
These are product requirements for later governed sprints, not discovery-time
implementation instructions.
