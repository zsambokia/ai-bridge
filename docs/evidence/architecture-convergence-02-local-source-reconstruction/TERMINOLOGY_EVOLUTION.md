# Terminology evolution

| Term | Source-derived meaning / correction | Evidence |
|---|---|---|
| Conversation | Interaction-to-Mission bridge; not mission decision owner. | `CHAT-0031`–`0032` |
| Context Package | Canonical package of resolved relevant context for consumers. | `CHAT-0045`–`0058` |
| Cognitive Profile | Resolved processing/evaluation policy; not Persona. | `CHAT-0045`–`0058`, `0113`–`0118` |
| Understanding Result | Immutable, historical structured interpretation/evidence; not observation or state mutation. | `CHAT-0085`–`0086`, `0131`–`0134` |
| Effective Scope (L0) | Boundary-effective context, policy, operation information and profile binding. | `CHAT-0173`–`0178` |
| Evidence (L1) | Contract-defined proof of legitimate production/handoff. | `CHAT-0161`–`0164`, `0180`–`0192` |
| Provenance/Causality (L2) | Canonical relations explaining source, cause, authority and lifecycle. | `CHAT-0194`–`0240` |
| Artifact (L3) | Immutable, versioned end product; contract determines persistence/lifecycle. | `CHAT-0155`–`0160`, `0245`–`0262` |
| Knowledge Candidate | Semantic unit selected from an Artifact for potential publication, not whole Artifact ingestion. | `CHAT-0263`–`0272` |
| Claim | Accountable, owner-bearing resolution object; not generic uncertainty. | `CHAT-0275`–`0290` |
| Factory Message / Packet (L4) | Domain-boundary carrier with envelope, delivery/interaction and payload semantics. | `CHAT-0301`–`0308` |
| FactoryIP | Full L0–L4 boundary stack. | `CHAT-0327`–`0330` |
| FFS | Factory Fabric Service: thin authoritative control-plane naming/routing service. | `CHAT-0311`–`0328` |
| Zoning | Canonical source→destination communication authorization, distinct from domain authorization. | `CHAT-0322`–`0328`, `0355`–`0358` |
| Factory Chat | Addressable FactoryIP UI node; not Runtime or Conversation owner. | `CHAT-0347`–`0350` |
| AI Kernel | A separately defined architectural concept, explicitly not Cognitive Processing. | `CHAT-0351`–`0352`, `0365`–`0366` |
