# Runtime 2.0 integration baseline

This baseline converges the existing Phase 1 operational components: canonical
`ExecutionRun` lifecycle, provider gateway, cancellation service,
provider-finish reconciliation, watchdog, activity projection, and Factory
Development execution-profile metadata. It creates no parallel Runtime, Engine,
Queue, Worker, Scheduler, Retry, Lifecycle, Planning, Workflow, or Conversation
system.

This is an integration baseline, not the Runtime 2.0 end-to-end architecture
acceptance. The separate Conversation Layer/MSM/Planning/Workflow convergence
requirements remain outside this no-feature scope.
